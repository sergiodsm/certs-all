# 06 — Governance risks & alerts

**Exam:** AB-900 · Domain 2 (35–40%) · Skill **2.3 Identify data protection and governance risks**  
**Skills measured as of:** July 22, 2026  
**Admin home:** [Microsoft Purview portal](https://purview.microsoft.com)

---

## 1. Official bullets covered

- Identify compliance risks and recommendations by using Microsoft Purview **Compliance Manager**
- Identify sensitive information by using Microsoft Purview **Data Explorer**
- Identify risks by using **Insider Risk Management**
- Identify and respond to alerts generated by Microsoft Purview **DLP**
- Identify policy violations generated by **Communication Compliance**
- Identify user activities reported by Microsoft Purview **activity explorer**
- Discover and manage AI activity by using **DSPM for AI**
- Search for files and emails by using **Content search** in Microsoft Purview **eDiscovery**

---

## 2. Why it matters on the exam

Skill 2.3 is a **tool-to-scenario matching** section. Stems describe a need (“see what the classifier matched inside a file,” “assess GDPR readiness,” “find emails for legal”). Your job is to pick the **named Purview tool**, not invent a clever workaround. Memorize the table in section 5 — it is the highest-yield object in this file.

## 3. Core concepts

### Compliance Manager

- Measures **compliance posture** against regulations/standards using assessments  
- Produces a **compliance score**, improvement actions, and recommendations  
- Use when the scenario is **regulatory readiness / gap analysis**, including generative AI–related templates where available  
- Not for real-time “block this email” enforcement

### Data Explorer

- Shows **sensitive content** inside items that classification has flagged (what matched)  
- Access is highly privileged (admin roles + Data Explorer viewer roles as documented)  
- Exam wording: **Data Explorer** (July 2026 outline). Older “Content explorer” is classic/legacy naming — prefer **Data Explorer** on AB-900  
- Use when you must **see the sensitive information itself**, not just activity counts

### Activity explorer

- Shows **user/admin activities**: label applied/changed/downgraded, sharing events, AI-related activities, etc.  
- Answers “**who did what with labels/sensitive data?**”  
- Does **not** replace Data Explorer’s content view

### Insider Risk Management (IRM)

- Detects **internal risk** indicators (data leaks, IP theft, risky AI usage templates)  
- Outputs risk **alerts/cases** for investigation  
- People-centric risk over time — not a one-off DLP tip for a single send

### DLP alerts

- Fired when DLP policies match (attempted sharing, Copilot processing restrictions, etc.)  
- Admins/investigators **identify and respond** (review, notify, remediate, tune policy)  
- Scenario keywords: alert, policy matched, sensitive data about to leave / blocked

### Communication Compliance

- Surfaces **policy violations** in communications (Teams, email, etc.) and AI interactions when configured  
- Investigators review and remediate **conduct/regulatory** issues  
- Scenario keywords: harassment, inappropriate language, regulatory communication rules, unethical AI prompts

### DSPM for AI

- Discover and manage **AI activity** and sensitive data exposure through AI apps (Copilot, agents, other generative AI as licensed/integrated)  
- Recommendations, data risk assessments, AI activity views  
- Scenario keywords: which AI apps, sensitive data in prompts, AI posture, oversharing risk via AI

### Content search in Microsoft Purview eDiscovery

- **Search** for files, emails, and other content for investigations/legal matters  
- Can include Copilot activity / interactions as searchable content types when supported  
- Exam phrasing: **Content search in Microsoft Purview eDiscovery** — not a separate retired classic portal  
- Scenario keywords: find specific emails/files, legal hold preparation, export for case

## 4. How it works (admin reasoning)

### Diagnostic flow

```text
What question am I answering?
  ├─ Regulatory score / improvement actions?     → Compliance Manager
  ├─ What’s inside the sensitive file?           → Data Explorer
  ├─ Who changed labels / sharing / AI events? → Activity explorer
  ├─ Employee risk pattern / exfil / risky AI? → Insider Risk Management
  ├─ Policy alert on sensitive spill/use?      → DLP alerts
  ├─ Conduct / message policy breach?          → Communication Compliance
  ├─ AI apps & sensitive AI interactions?      → DSPM for AI
  └─ Find emails/files for a case?             → Content search (eDiscovery)
```

### Responding to DLP alerts (fundamentals level)

1. Open alert in Purview  
2. Confirm matched policy, user, location, sensitive types  
3. Decide: false positive vs real risk  
4. Remediate (user coaching, revoke sharing, tune policy)  
5. Document / close  

You are not expected to design complex rule logic on AB-900 — you must **know that DLP alerts exist and where they live**.

### eDiscovery vs explorers

| Need | Tool |
|------|------|
| Ad-hoc legal/investigation search across mailboxes/sites | **Content search (eDiscovery)** |
| Browse classified sensitive item content | **Data Explorer** |
| Browse labelling/sharing/AI activity | **Activity explorer** |

## 5. Compare / choose (critical)

### Symptom → tool (memorize)

| The scenario says… | The answer is… |
|--------------------|----------------|
| Assess compliance against a regulation; get improvement actions / score | **Compliance Manager** |
| See the **actual sensitive content** matched by classification | **Data Explorer** |
| Employee may be exfiltrating IP or showing **risky AI usage** | **Insider Risk Management** |
| An **alert** fired because sensitive data was shared / Copilot processing blocked | **DLP alerts** |
| Message or AI prompt breached **business-conduct / regulatory communication** policy | **Communication Compliance** |
| Who applied, changed, or **downgraded** labels; sharing or AI **activities** | **Activity explorer** |
| Discover/manage **AI activity** and sensitive data in AI apps | **DSPM for AI** |
| **Search** for specific files and emails for a legal/investigation matter | **Content search in Purview eDiscovery** |

### Easy confusions

| Pair | Difference |
|------|------------|
| Data Explorer vs Activity explorer | **Content of items** vs **who did what** |
| Compliance Manager vs DLP | **Posture/score** vs **runtime prevention + alerts** |
| IRM vs Communication Compliance | **Risk cases / behavior patterns** vs **message policy violations** |
| DSPM for AI vs Activity explorer | **AI posture & discovery** vs **activity feed** (related but different primary purpose) |
| Content search vs Data Explorer | **Find items for a case** vs **inspect classified sensitive content** |

## 6. ⚠️ Exam traps

- Don’t overthink: pick the tool whose **primary purpose** matches the stem.  
- **Data Explorer** is the July 2026 name for identifying sensitive information — don’t default to old “Content explorer” wording unless the question uses it.  
- **Content search** lives under **Purview eDiscovery**, not a standalone classic Content Search product.  
- Compliance Manager does **not** block emails in real time.  
- Activity explorer does **not** show full sensitive item content the way Data Explorer does.  
- IRM alerts ≠ DLP alerts (people-risk cases vs policy match on content movement/use).  
- DSPM for AI is for **AI activity/posture**, not generic Secure Score.  
- Retired portal names (`compliance.microsoft.com`) are wrong — use **purview.microsoft.com**.

## 7. Hands-on checklist

- [ ] Purview → **Compliance Manager** → open an assessment; note score and an improvement action  
- [ ] Purview → Information Protection → **Data Explorer** (if role allows) — understand sensitivity of access  
- [ ] Purview → **Activity explorer** — filter for label changes or AI-related activities  
- [ ] Purview → **DLP** → Alerts — open one alert (or sample) and note matched policy fields  
- [ ] Purview → **Insider Risk Management** — view policies/alerts UI  
- [ ] Purview → **Communication Compliance** — view policies/pending reviews  
- [ ] Purview → **DSPM for AI** / DSPM — AI activity or recommendations  
- [ ] Purview → **eDiscovery** → Content search — run a simple keyword search in a lab case  

---

## 8. Checkpoint

1. Which tool provides a compliance score and improvement actions against a regulation?  
2. You need to see the credit-card numbers inside documents classification flagged. Which tool?  
3. Investigators need all emails and files for a departing employee’s legal matter. Which tool?  
4. A DLP policy blocked a sharing attempt and created a notification for admins. Where do you respond?  
5. Match: (a) label downgrade last week (b) unethical Copilot prompts (c) AI app posture dashboard  

### Answers

1. **Compliance Manager**  
2. **Data Explorer**  
3. **Content search in Microsoft Purview eDiscovery**  
4. **Microsoft Purview DLP alerts**  
5. (a) **Activity explorer** (b) **Communication Compliance** (c) **DSPM for AI**
