## Question format (every item)

- Scenario-first stem  
- Options A–D or A–E  
- **Correct answer** · **Why correct** · **Why distractors fail** · **Mapped skill**  
- ⚠️ Trap flags where a common mix-up applies  

Multi-select items say **Select N** — pick exactly N options.
