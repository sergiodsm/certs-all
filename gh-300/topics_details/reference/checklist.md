# Pre-Exam Mastery Checklist

Use with [`../../gh-300-topics.md`](../../gh-300-topics.md). Check only what you can **teach or configure**, not merely recognize.

- [ ] List LLM limitations that matter in IDEs

## Domain 4 — Prompt engineering
- [ ] Apply 4S framework to a weak prompt
- [ ] Write zero-shot and few-shot versions of one task
- [ ] Debug “bad Chat answer” via missing context
- [ ] Create an instructions file and a prompt file

- [ ] Draft docs without inventing behavior
- [ ] Produce synthetic sample data (no PII)

- [ ] State PR summary capabilities vs non-capabilities
