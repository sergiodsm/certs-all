# Glossary (GH-300 Vocabulary)

| Term | Definition for the exam |
|---|---|
| **Inline suggestions / ghost text** | Completions shown while typing; accept/reject/edit |
| **Copilot Chat** | Conversational assistant with context attachments and history |
| **Edit Mode / Copilot Edits** | Multi-file proposed edits for selective human acceptance |
| **Plan Mode** | Planning-focused flow; emphasize approach before edits |
| **Agent Mode** | Autonomous multi-step loop: edit, run tools, iterate |
| **Sub-Agent** | Delegated specialized agent with isolated/optimized context |
| **MCP** | Model Context Protocol — standard way to attach external tools/context |
| **Copilot CLI** | Terminal-oriented Copilot assistance for commands/scripts/sessions |
| **Spaces** | Curated context collections for grounded conversations |
| **Spark** | Lightweight app/prototype generation capability (know existence/use) |
| **Instructions file** | Persistent coding/review norms for Copilot |
| **Prompt file** | Reusable task-specific prompt template |
| **Content exclusion** | Admin patterns that block files as suggestion targets/context on supported surfaces |
| **Public-code matching / duplication detection** | Filter/warn/block suggestions that closely match public GitHub code |
| **IP indemnity** | Business/Enterprise contractual protection posture tied to public-code controls |
| **Prompt building** | Assembling model input from intent + available context |
| **Proxy filtering** | Intermediate policy/safety processing on the Copilot service path |
| **Post-processing** | Filters after model output (safety, quality, public-code, etc.) |
| **Zero-shot** | Task prompt without worked examples |
| **Few-shot** | Task prompt with one or more examples |
| **Hallucination** | Plausible but false output (APIs, facts, packages) |
| **Over-reliance** | Accepting AI authority without adequate human oversight |
| **Audit log** | Org/enterprise record of admin/security-relevant events including Copilot changes |
| **Premium requests / AI credits** | Billable units for higher-cost interactions (models/agents); confirm current naming |

## Confusable pairs

| Don’t confuse | With |
|---|---|
| Content exclusion | `.gitignore` |
| Public-code Block | License spdx auto-rewrite |
| Edit Mode | Full Agent autonomy |
| Telemetry retention | “Training on your private repos” (plan-dependent; not identical) |
| Fairness | Inclusiveness |
| Ownership of suggestions | Permission to skip review |
