# AI-200 Glossary

| Term | Definition |
|------|------------|
| **ACR** | Azure Container Registry — store/version container images |
| **ACR Tasks** | Cloud-native image build in ACR |
| **AKS** | Azure Kubernetes Service |
| **App Configuration** | Centralized settings and feature flags |
| **Change feed** | Cosmos DB ordered stream of item changes |
| **Container Apps** | Serverless container hosting with revisions |
| **DLQ** | Dead-letter queue — failed messages after max retries |
| **Embedding** | Numeric vector representing semantic meaning of text |
| **Entra ID** | Microsoft identity platform (formerly Azure AD) |
| **Event Grid** | Event routing/pub-sub for reactive workflows |
| **Grounding** | Constraining LLM answers to retrieved evidence |
| **HNSW** | Graph-based approximate nearest neighbor index (pgvector/Redis) |
| **Idempotency** | Repeated processing yields same result, no duplicate side effects |
| **KEDA** | Kubernetes Event-driven Autoscaling |
| **Key Vault** | Secret/key/certificate storage with rotation |
| **KQL** | Kusto Query Language for Log Analytics |
| **Managed identity** | Azure-automatic service principal for resources |
| **Metadata filter** | Restrict vector search by tenant, ACL, category, etc. |
| **MI** | Managed identity |
| **OpenTelemetry (OTel)** | Vendor-neutral tracing/metrics/logs standard |
| **pgvector** | PostgreSQL extension for vector similarity |
| **RAG** | Retrieval-Augmented Generation |
| **RBAC** | Role-Based Access Control |
| **Revision** | Immutable Container Apps deployment snapshot |
| **RU** | Request Unit — Cosmos DB throughput/cost unit |
| **Service Bus** | Enterprise message broker (queues, topics) |
| **Vector similarity search** | Find nearest embeddings by distance metric |
