# Module 08 — IPv6

## In one sentence

OpenWrt IPv6 combines **interface delegation** (from WAN), **odhcpd** (RA + DHCPv6 on LAN), and **fw4** zone policies — all configurable via UCI and inspectable with **`ip -6`**.

## Commands

```sh
uci show network | grep -i ipv6
uci show dhcp | grep -E 'dhcpv6|ra'
ip -6 addr show
ip -6 route show
logread -e odhcpd
logread -e odhcp6c
ifstatus wan6
ubus call network.interface.wan6 status
ping -6 openwrt.org
```

## WAN IPv6 modes

### DHCPv6 (typical ISP)

```sh
config interface 'wan'
    option device 'eth1'
    option proto 'pppoe'        # or dhcp
    option ipv6 'auto'

config interface 'wan6'
    option device '@wan'
    option proto 'dhcpv6'
    option reqaddress 'try'
    option reqprefix 'auto'     # request PD (/56 or /64)
    option peerdns '1'
```

CLI:

```sh
uci set network.wan.ipv6='auto'
uci set network.wan6=interface
uci set network.wan6.device='@wan'
uci set network.wan6.proto='dhcpv6'
uci set network.wan6.reqprefix='auto'
uci commit network
/etc/init.d/network restart
ifstatus wan6
```

### Static IPv6 WAN

```sh
uci set network.wan6.proto='static'
uci set network.wan6.ip6addr='2001:db8::2/64'
uci set network.wan6.ip6gw='2001:db8::1'
uci commit network
/etc/init.d/network restart
```

## Prefix delegation (PD) to LAN

Assign part of ISP prefix to LAN:

```sh
config interface 'lan'
    option ip6assign '64'       # subnet size from delegated prefix
    option ip6hint '0001'       # optional sub-prefix id
    option delegate '1'
```

```sh
uci set network.lan.ip6assign='64'
uci commit network
/etc/init.d/network restart
ip -6 addr show dev br-lan
```

Router advertises delegated prefix on LAN via **odhcpd**.

## LAN RA / DHCPv6 (odhcpd via dhcp config)

```sh
config dhcp 'lan'
    option interface 'lan'
    option dhcpv6 'server'
    option ra 'server'
    option ra_slaac '1'
    option ra_management '0'    # 0=SLAAC+stateless DHCP, 1=DHCP only, 2=SLAAC only
    option ra_flags 'managed-config'
    option ra_default '1'       # advertise as default router
```

Modes cheat sheet:

| ra | dhcpv6 | Client behavior |
|----|--------|-----------------|
| server | server | SLAAC + DHCPv6 options |
| server | disabled | SLAAC only |
| disabled | server | DHCPv6 only |
| relay | relay | Relay to upstream |

```sh
uci set dhcp.lan.ra='server'
uci set dhcp.lan.dhcpv6='server'
uci set dhcp.lan.ra_slaac='1'
uci commit dhcp
/etc/init.d/odhcpd restart
/etc/init.d/dnsmasq restart
```

## Disable IPv6 on LAN (IPv4-only LAN)

```sh
uci set network.lan.delegate='0'
uci set dhcp.lan.ra='disabled'
uci set dhcp.lan.dhcpv6='disabled'
uci commit
/etc/init.d/network restart
/etc/init.d/odhcpd restart
```

## IPv6 DNS

Clients get DNS via RA RDNSS or DHCPv6 — dnsmasq integrates:

```sh
uci add_list dhcp.@dnsmasq[0].server='2001:4860:4860::8888'
uci commit dhcp
/etc/init.d/dnsmasq restart
```

## Firewall (IPv6)

Zones include `wan6` network on **wan** zone by default. Forwarding `lan → wan` applies to IPv6 unless restricted.

Block all IPv6 from WAN to router:

```sh
# Default wan input REJECT already applies
uci show firewall | grep -A5 "name='wan'"
```

IPv6 **does not use NAT** the same way as IPv4 (NPT exists but rare). Clients use global or ULA addresses.

## ULA (Unique Local Address)

Internal fallback prefix:

```sh
uci set network.globals.ula_prefix='fd00:1234:5678::/48'
uci commit network
/etc/init.d/network restart
```

Generated automatically if section exists in `network` globals.

## Static IPv6 on LAN host (DHCPv6 reservation)

```sh
uci add dhcp host
uci set dhcp.@host[-1].name='server6'
uci set dhcp.@host[-1].mac='AA:BB:CC:DD:EE:FF'
uci set dhcp.@host[-1].ip='2001:db8:1::100'    # IA_NA — depends on setup
uci set dhcp.@host[-1].hostid='::100'          # suffix under delegated prefix
uci commit dhcp
/etc/init.d/odhcpd restart
```

Exact options vary by delegation layout — verify with `uci show dhcp` examples on wiki for your release.

## Testing connectivity

```sh
# Router
ping -6 -c 3 2001:4860:4860::8888
ping -6 -c 3 openwrt.org

# Check RA on LAN (from client or tcpdump on router)
tcpdump -i br-lan -n icmp6 and 'ip6[40] == 134'   # Router Advertisement

# Client got prefix?
logread -e odhcpd
```

## Common mistakes

1. **No `wan6` interface** — `ipv6 auto` on WAN alone may not request PD without `wan6`.
2. **`ip6assign` too large** — ISP gives /56; assign /64 per interface, not /48 without planning.
3. **Firewall zone missing wan6** — IPv6 bypasses expected policies.
4. **ISP uses DHCPv6-PD only on specific VLAN** — wrong WAN device.
5. **Testing IPv6 with IPv4-only tools** — use `ping -6`, `curl -6`.

## IPv6-only troubleshooting order

```text
1. wan6 has global address?     → ip -6 addr show dev eth1
2. PD delegated?                  → ifstatus wan6 | jsonfilter -e '@.["ipv6-prefix"]'
3. LAN has /64 from PD?           → ip -6 addr show br-lan
4. RA running?                    → logread -e odhcpd
5. Forward + DNS?                 → ping -6 from LAN client
```
